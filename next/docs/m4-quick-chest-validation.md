# M4 快速开箱链

## 实现

固定旧 `Factory.StateChest` 的 quick 分支只有在点到 chestFlag 后才执行三次角色选择、30 次拆陷阱、三轮 `(1,1)` 与拆陷阱退路，然后回普通处理。新版此前只保留了一个选择点和单个拆陷阱上限，没有完整承接这条链。

当前在既有 `chest::open_chest` 编译器中补齐上述有限节点，未增加另一个执行器。选择点每次只在 whowillopenit 场景有效；已进入 opening 立即停止多余选人。所有拆陷阱和退路点都由新帧宝箱上下文授权，遭遇战斗/复活/善恶选择立即返回外层。拆陷阱后出现阻塞层仍标记结果未确认。

WHO=0 在旧 quick 分支计算得到第六人的位置，这里保留实际坐标；普通分支的 0 仍按既有角色选择规则处理。Quick 不检查 fear 是旧语义，普通分支仍检查 fear。

子图总预算为 240 秒，保证显式重试链有容纳空间，但不改变帧 TTL、停止门禁或节点次数。普通路径拆陷阱仍是 8 次；普通路径全部循环与可用角色池的完整承接另列剩余，不把本阶段当成 StateChest 全部分支已迁移。

## 验证状态

待构建验证：40 次完整快速输入、快速响应只需 3 次、拆陷阱后转战斗或阻塞立即停止。现有选人、恐惧、停止/拒绝及转场测试应回归。测试图片为合成，生产配置和真实游戏未操作。
