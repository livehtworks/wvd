# M4 重启后防空气墙动作

## 固定源语义

旧 `StateDungeon` 在角色恢复之后，仅对 dungeon 类型、开启 `BYPASS_THE_WALL` 且重启后尚未执行的情况，发送从 (300,950) 到 (600,950) 的滑动，再点击 (27,950)、(853,950)。前两步各等一秒，最后置 `_BYPASSAFTERRESTART`。它表示动作已尝试，不证明物理引擎已经恢复。

## 新链

`traverse_dungeon` 的恢复子图之后接 `navigation::bypass_wall_after_restart`；地图分支不执行，专项 quest 不执行。初始阶段为 3，游戏重启才归零。三个阶段由独立事件确认，`bypass_after_restart` 从阶段派生，不保存第二份布尔权威。

每个动作仍需当前地下城场景，滑动沿用现有编译器的固定 Swipe 映射。动作返回后用新帧确认已知场景，再推进阶段。战斗/提示插入时交回外层，不把方向点击继续发给新界面；恢复后只处理剩余阶段。真正游戏重启创建新序号，旧回执不能完成新序号。没有恢复出厂状态、任意 Shell 或真实设备输入。
