# Windows 功能交付

## 启动

双击 `next/dist/wvd-next/启动WVD新版.bat`。程序会打开本地工作台，默认地址为
`http://127.0.0.1:17652`。新版数据写入 `%LOCALAPPDATA%\WvdNext`，不覆盖旧版配置、mod 和日志。

## 使用顺序

1. 在“工作台 / 模拟器”确认 MuMu 启动程序、ADB 地址、实例编号和 Clash/VPN 开关，保存配置后连接并截图。
2. 在“目标、探索、战斗、战斗方案”选择任务和策略并保存；任务专用配置只作用于当前任务。
3. 直接点击“开始任务”运行现有任务，或进入“流程编辑”新建/复制流程，保存后运行。
4. 运行区显示后端真实状态、当前步骤、耗时、输入统计、错误和诊断图；“停止”请求作用于界面显示的同一个 Run。

## 流程编辑

- 可新建、复制、保存、重载、删除，也可把已有地下城任务生成可编辑副本。
- 节点支持模板/OCR/WVD 识别、点击/滑动/返回、等待、战斗、开箱、业务确认、现有任务阶段和结束。
- 顺序、有序候选和失败出口是独立连接语义；有限重复配置在节点上。
- “调试选中节点”只运行服务端已保存版本。试识别可使用当前截图或 900x1600 本地 PNG，且不会点击设备。

## 已做的有限实操

- 打包版启动和 API 可用。
- 从页面连接明确选定的 MuMu 实例并取得真实截图。
- 从页面启动并停止三段可中断等待流程，结果为 `UserStopped`，设备输入为零。
- 已有任务可生成可运行的编辑副本。
- 本地图片模板识别与 WVD Pause 识别均返回真实三态结果。

真实游戏任务由用户从界面主动启动。本轮没有用全任务遍历、测试 EXE 或假设备结果代替产品交付。
