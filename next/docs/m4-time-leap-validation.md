# M4 无因果调整的时间跳跃组件

## 范围与调用边界

`navigation/time_leap.*`对应固定旧源码`CursedWheelTimeLeap`中CSC_symbol=None的调用。
它是供manualSepDemon及部分专项复用的有限Maa图，不是整个任务，也不处理因果选项。
需要CSC的调用仍未承接，不能将它们导向此函数来跳过功能。

保持可见目标的快速路径；否则十次左页签、选择章节、三次大滑动、反向细滑找目标。
跳跃仍在明确leap按钮后执行；按钮消失且新帧正常场景成立才完成。
初始城市画面不能直接被算作跳跃完成，未知页不盲点。
下载许可显式冻结；拒绝时零输入，沿用boot.download_permission_missing。
180秒Session与有界节点计数，所有输入继续由GuardedAction/InputGate确认。
