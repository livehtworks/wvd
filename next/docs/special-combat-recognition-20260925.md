# 特殊敌人战斗分流（2026-09-25）

## 本轮实现

- 任务配置的 `TASK_POINT_STRATEGY.special_combat` 提供“红骷髅”和“行动栏头像”两个复选框。两项同时开启时，任一识别命中即可选特殊敌人方案；两项都关闭时沿用旧战斗入口。
- 启用分流时，必须分别选择普通敌人和特殊敌人的战斗方案。一次遭遇只在首次确认时确定方案，不因回合中头像排序变化反复切换。方案改名和删除保护包含这两个引用。
- 分类先确认战斗指令栏已经出现，再搜索红骷髅的战斗上半部 ROI 或左侧行动栏 ROI。头像在整条行动栏内搜索，不使用第六格的固定坐标。
- `combat_special_skull.png` 和 `combat_scorpion_portrait.png` 取自同一场蝎女战斗的实帧，源文件在 `next/resources/images/`，运行成员在 `next/packs/wvd/image/`。原有 `skull.png` 是死亡提示，不参与本识别。

## 验证边界

- 900x1600 的两张蝎女战斗帧：红骷髅、头像模板均命中；入战前的迷宫帧：两者均未命中。正式识别接口在隔离服务上复核的命中框分别为 `(282,400,28,38)`、`(50,475,65,48)`。
- 独立数据目录的配置保存与读回通过，仍为原 33 个顶层字段；原生定向断言覆盖双开关、各单开关、全关旧入口和 A/B 方案选择；前端与原生构建通过。
- 已更新 `next/dist/wvd-next-native` 候选并重启本地服务 `http://127.0.0.1:17652/`；页面返回 200，新控件文字和两张模板在候选包内。当前真实用户配置未被自动改动，两个勾选框默认关闭。
- 本轮没有在真实蝎女战斗中释放技能或验证 A/B 实际作战结果。头像可能被换皮怪复用，红骷髅只能证明特殊标记；用户开启任一条件即接受对应的误判范围。两者均未命中时按普通方案运行，不能据此证明没有特殊怪。
- 当前仅提供已裁好的蝎女头像模板。其他怪物可按同样方式新增资源，但本轮没有实现运行时上传任意头像图片。
