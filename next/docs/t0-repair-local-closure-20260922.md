## 真实失败与修复

1. `4BA41965-E01C-4475-8184-9FBADB36D9C2 / run 1`：`VPN_UI_DUMP_FAILED`。MuMu Android 15 的 `uiautomator dump` 崩溃；输入计数全为 0。修复为严格包名、顶层 Activity、帧尺寸门禁下的单次启动卡片点击，点击后复核 VPN。
2. `D460F165-2E35-4E97-963E-2E6DC8E969EB / run 1`：VPN 与游戏启动均确认，随后 `recovery.boot_ready.budget_exhausted`。诊断图是繁中免责声明，现有模板对该图离线分数约 `1.0`；首轮扫描发生在页面出现前。修复为未知帧 `500ms` 可取消等待后回到 Boot 入口，仍受原 `120s` 总预算和识别 Error 立即失败约束。
3. `CE56832C-15AD-4E82-B715-A0766D818978 / run 1`：`VPN_UI_FALLBACK_UNCONFIRMED`。安全门禁未点击；实际 `MUMU_EXTRAS` 帧为 `900x1600`，而门禁只接受 `1600x900`。已将目标限定为两种实测方向，坐标分别为 `(450,243)` 和 `(800,243)`；按停止规则未再次真实启动。
