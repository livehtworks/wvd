# M4 要塞八层陷阱专项

## 业务边界

固定旧 `fortress-B8F_trap` case 是不回城循环：每轮开始累计时间并增加 `_COUNTERDUNG`，按七个 TargetInfo 执行 StateDungeon，遇停止退出。它没有 `_EOT`，不能拿同名普通 dungeon 的入本或回城配置代替。

`tasks/fortress_trap` 编译一个完整有限迭代，入口只接受本内稳定场景，普通阻塞交回共用子流程。`WvdTaskPlan::with_route` 保存局部 TargetInfo，不改写目录原树。开始次数和完成次数分开，恢复同一迭代不重复开始计数；七点未完成不能走成功出口。后续重复迭代仍需 Run 的正常续段，不借重启实现循环。

标记自动移动停止后的地图确认缺项在本次依赖修正中承接，见 `m4-auto-map-validation.md`。所有按键和滑动继续经过实际 Maa、GuardedAction 和 InputGate。
