## 1. 什么算实机证据

指当前 Windows 程序，通过已配置的 MuMu 实例，操作真实联网 WVD 客户端。不是手工操作后声称自动成功，不是假设备、合成贴图、测试 EXE，也不要求另购或另接实体手机。

所有功能运行均从交付候选的工作台触发，走同一个 Application、已保存流程、冻结配置、发布器、执行器和设备后端。记录该次 EXE/源码/运行资源版本与 Run ID。不得通过临时 Python/ADB 点击脚本替产品完成步骤。

编译、静态审查、哈希核对、导入表检查仍要做；它们不是游戏验收。默认不执行 `validate.py`、`test_native_*`、全量 pytest/ctest 或旧任务矩阵，不再新增模拟场景数量来替代实机效果。

读取当前用户配置来确定 MuMu 路径、实例号、ADB序列和游戏包，不把过去的“实例2”硬写进代码。确认旧程序与其他控制者不在操作该实例，只清理本工具明确拥有的旧候选进程。

核对本包关键修复及本地补齐已编译到同一候选；UI 状态/停止链能真实响应；保留旧发行目录和用户数据。不得在明知代码编译失败、输入停止仍可漏发时直接启动实机。

首次现场开始前向用户显示本轮路线和允许的副作用。当前可直接推进的低风险范围是：连接、读画面、启动已配置的游戏/已启用的VPN、城市菜单进入/退出、编辑保存/参数覆盖、可逆列表滑动和停止。

## 3. 验收序列

### L01 正式启动、截图、停止和重新连接

用工作台连接当前选定实例，核对帧大小、方向、前台、设备/连接代次和图像。需要启动时使用正式开始入口，先确认VPN，再确认游戏就绪；已有前台游戏不先强停。

验证一次取消正在准备的开始请求：停止后不能在慢连接返回时新发 VPN/游戏点击。区分已发送的在途动作和停止后的新业务申请；前者不能承诺撤回。退出不关闭用户的 MuMu，不杀共享ADB。

四种 VPN/游戏初态只验证本轮实际取得、或用户同意准备的组合。没有准备到的组合记 `NOT_OBSERVED`，不靠假返回值补 PASS。

### L02 公共步骤/块的实际复用与循环

使用当前真实繁中城市/公会/委托/悬赏列表路径。没有“接取悬赏”：普通委托接案和悬赏提交不能混淆。先走仅打开页面/返回的路线。

从编辑器保存公共调用，参数确实传到执行。通过两轮可逆菜单往返确认同一输入节点第二次仍进入后置观察；检查 @await 次数、事件禁用继承和原作者节点来源。不要只新建两个不同调用各跑一次来回避同节点重复。

结果检查包括页面实际变化、业务确认是否报 FRAME_STALE、输入次数、后置结果、停止位置、重新打开编辑器后定义是否一致。没有跳轮的这条路线只能证明页面可进入，不能说赏金已刷新。

### L03 已知跳轮路径（仅在本地明确授权后）

沿仓库已有、实操确认过的章节和目标流程执行，不编造新路线或修改列表方向。目标未出现才按既定方向滑动；告知页可选，不是刷新成功的必经页面；王城证据不能用任意城市图标代替。

通过工作台完成一次限定流程并返回明确地点。记录输入→网络等待→新帧观察；自然出现超过两秒的等待时保留实际耗时，不需要人为凑 4253ms，也不应因此拒绝已经识别成功的结果。

### L04 走到一半遇怪/开箱（仅在本地选定的安全路线内）

保留原 task_step/目标/策略配置。自然遇怪后只由一个处理器接管，战斗完成后重新观察原目标；不把“打完怪”直接当成“到达任务点”。开箱使用已有角色选择/恐惧/恢复规则，不为了新架构删掉原规则。

核对计数各增加一次、策略频次按旧语义消费、公共调用返回范围正确、没有因处理时间而误判父阶段超时。出现箱→战斗→网络的嵌套时才记录此分支；没有遇到时记缺口，不为了刷到事件无限走图。

### L05 网络覆盖层与非幂等结果

优先观察现场自然出现的网络重试/暂停。如果要主动断开该模拟器所用VPN，必须在用户已确认的安全页面进行，并事先确定恢复方法；不关闭主机网络、不动其他实例、不在领取/报告/购买提交中制造断网。

覆盖层出现时底层背景仍可命中，程序也不能先点击背景。处理后重新检查原结果。对于已发送而结果未知的操作，必须保留未知事实、禁止自动重发；不能靠实际多领一次来证明“没重复”。

### L06 实际停止与清理

在本轮实际能达到的准备、截图、等待、识别、可逆滑动、事件处理阶段执行停止。日志应标明取消接受时间、已在途动作、最后一个新业务申请及清理UP/KeyUp。停止只能承诺工具不再提交新业务操作，不能声称服务器/游戏被暂停。

主服务继续响应；最终自有控制客户端/CaptureHost退出与输入释放有证据。若释放未知，UI显示清理未确认并保留租约，不能伪报 `STOPPED` 或放行下一任务。

首次 OCR 初始化和推理中取消要在实际适用素材上验证；当前只有锁定英文OCR，不能修改游戏语言、伪造英文图或把繁中模板命中算成OCR通过。没有适用现场就明确保留该覆盖缺口。

### L07 维护、真正未知、坏资源

官方维护无法按需制造。只有真实维护画面和实际匹配证据才能写实机通过；没有可靠素材时不得猜测为维护，也不得自动重启。

真正未知页面和明确识别 Error 分开。已经登记但缺失/损坏的资源应在相关流程准备期清楚拒绝，不拿真实账户反复试点。不故意破坏用户资源来补测试；没有自然出现的错误路径记录代码复核/未现场覆盖，而非 PASS。

### L08 全工作台与候选退出

核对用户实际使用的模拟器、目标、探索反向 SKIP、战斗方案/任务点、公共定义展开返回、编辑保存、预览、结果与历史。调整现有数据先备份，不复制旧生产配置回去覆盖当前副本。

候选目录必须就是刚才验证的 EXE/依赖/前端；检查运行模块无 Maa。正常退出后端口和自有 helper 释放，用户模拟器仍保留在记录的状态。

## 4. 安全停止条件

发生目标实例不一致、来源/图像不一致、停止后新发业务输入、同一动作重复提交、事件返回错层、误推进任务点、自动重启模拟器、清理未知却释放租约、模型/资源缺失却盲点继续时，立即关闭新输入并保存这一次失败。

不允许无修改地反复重跑直到偶然成功。定位对应代码并修正、重建同一候选后，只重跑受影响的这条实际路线，不扩成全部旧任务矩阵。
