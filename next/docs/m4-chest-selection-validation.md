# M4 普通开箱与候选池

## 职责与旧语义

固定 `Factory.StateChest` 使用六人可用池，遇恐惧移出；指定角色仅第一次优先，之后在剩余池随机选择，每轮八次拆陷阱后重新识别。

新版 `chest::Selection` 只保存候选编号、随机状态和尝试次数，由 WvdRunState 独占；`WvdChest` 从实际同帧的六个角色 ROI 收集恐惧证据，不点击。编译器选择对应固定位置的 GuardedAction，再以新帧记录 `chest_character_attempted`。点击返回不是开箱完成，仍须回地下城才能计箱数。

一次原生子调用最多六轮，仍未结束则以 `RetryExit` 返回任务分派。正常回跳只清节点预算，不清 Run 候选池，父 Session 总时间不重新开始。独立调用返回 Interrupted，恢复策略不会为此重启设备。没有开启第二个任务循环。

普通中断清理未完成选择，但同一宝箱的候选池保留；下一次真实宝箱才重置。恐惧观察到最终点击间再次变更则不点该角色，转下一轮重新取图。种子随编译参数封存；不声称与旧 Python RNG 的逐个随机数相同。
