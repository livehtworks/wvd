# M4 回城补给与住宿回执

## 实现范围

`tasks::prepare_departure` 是 DungeonFarm 外层的回城/补给子图，到可执行 EOT 的城市或入口结束，不执行完整刷本循环。它复用世界移动、队伍重组、旅店住宿，不另建任务执行器。

- 保留旧入口差别：returntoTown 考虑普通住宿和队伍周期；openworldmap 只考虑普通住宿；已在世界地图则按任务 RTT 回城。强制补给不受普通间隔限制。
- 重组队伍结束并回到城市才记六小时周期；组队本身不记住宿。普通住宿仍独立判断。
- 住宿确认画面消失、重新出现 Stay 后，用新帧记录本轮住宿回执，再执行退出旅店。退出失败保留已住宿事实，同一轮再次调用不重复付费。
- 回执跨普通段/恢复代次保留，真正再次入本才清除。旧回执重放不能把新一轮标成已经住宿。
- 处于旅店但没有已确认回执时返回 `departure.inn_payment_unconfirmed`；RTT 缺失或已经进入地下城也有明确出口，不发猜测点击。

独立 UI 子图仍可不持有 WvdRunState；完整业务显式启用回执。条件只读选路，不能用于输入授权，确认仍要求当前视觉证据。源码中的 profile 不写回旧 config。
