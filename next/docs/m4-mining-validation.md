# M4 挖矿有限链

## 代码范围

`tasks/mining.*` 编译FFXI-Org的入本、标记寻路、矿点确认、挖取/奖励页、无矿退出，以及
无镐子后的返城、FFXIStone组队和真正住宿。沿用原EOT/RTT，不购买工具、不清包或卖装备。
所有输入仍通过新帧GuardedAction，未知/失败交回既有协调器；本轮仅运行隔离离线设备。

`mining/Progress` 是WvdRunState内的业务子状态，不持设备或图像，不是另一个执行器。
奖励按旧十项顺序取最高分，必须严格大于0.9；ROI保持[4,664,890,283]，无法判断计unknown。
同页重复观察幂等，页面消失后才允许下一奖励；同页分类改变保留冲突，不能加两种计数。
矿点仍为[692,68,140,140]，无矿提示仍为[320,667,423,474]。

补镐子标志跨恢复保留，组队后只进入住宿阶段；实际住宿回执确认前不清标志。
矿物统计与普通战斗/副本次数分开。本有限段预算900秒，节点命中上限明确；不据编译成功
或部分子图通过宣布无限挂机、资源稳定或完整58项任务通过。
