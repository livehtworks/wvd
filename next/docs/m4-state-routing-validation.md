# M4 普通插入与状态分派验证

## 已实现

- 业务摘要条件只支持列出的标量字段及等于/计数下限比较，用于 Maa 候选分派，不引入脚本解释器。
- 业务状态每次受控更新使识别缓存版本失效。同一帧也不能复用状态更新前的条件结果。
- 状态条件始终 `action_eligible=false`，不能仅靠任务步或计数授权输入；组合条件不能洗掉该限制。
- 子流程组合只将调用者明确指定的普通插入出口绑定到外层后继，其他恢复出口仍结束 Session 请求恢复。
