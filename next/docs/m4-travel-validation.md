# M4 世界地图往返与组队住宿

## 已实现

- `navigation/world_travel.*` 按类型区分回城与前往地下城入口。从已知入口打开世界地图，目标缺失时使用任务提供的滑动与取消点；每个候选点重新定位，确认目标场景后立即退出。未知画面不发送地图坐标，不调整地图缩放。
- 场景暂时消失后的点击后置等待为有界 22 秒；图节点次数和 Session 总预算仍保留。输入发出不代表入城。
- `supply/party.*` 按公会、编辑、队伍管理、选择队伍、组装、确认和返回城市分步骤执行。可绑定默认位置或任务提供的队伍图片。
- `assemble_and_rest` 将组队和旅店作为两个独立子流程。只有完成后续住宿和离店才完成整个补给段，组队本身不记为已补镐子。
- 旧 `reunionParty` 使用小写 `ok`，实际资源为 `OK.png`；新版引用唯一的正式资源名，不在 Windows 上生成仅大小写不同的两个文件。
- 对照固定旧源码：`reunionParty` 1819、`TeleportFromCityToWorldLocation` 1935、`TeleportFromDungeonToCity` 1973、`StateInn` 2463。
