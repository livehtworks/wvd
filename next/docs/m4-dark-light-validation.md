# M4 暗灯与遭遇超时

## 实现范围

依据固定旧源码 `QuestFarm` 的 `darkLight` 分支，新增独立有限Pipeline，使用已有战斗、开箱、
复活、面板恢复和公共提示子流程。任务不主动入本、不作普通副本计数、不执行开始时恢复；
战斗或宝箱结束后的恢复仍由原SKIP字段决定。灯与点灯确认都需要新帧前置和后置证明。
点灯后仍在同一弹窗将报后置超时，不重放点击或自动重启去掩盖失败。

`dark_light_active` 属于WvdRunState，只保存当前Run业务进度；生命周期恢复保留它，不保留
图像和输入许可。遇已知回城页面终结本有限段，不声称完成全部暗灯挂机任务或真实游戏验证。

地下城与暗灯的未处理页面出口增加遭遇超时条件：仍待结算的战斗或宝箱超过400秒才命中，
恰好400秒不命中；恢复正常地下城或重启后清空相应计时。正常已知处理分支优先，超时本身
不是截图匹配结果，也不授予输入。MAX_TRY_LIMIT、7300秒和任务交接仍是独立未完成项。
