# 设备与输入层（M2 / M3）

`DeviceBackend`、`NativeInputGate` 与指定设备 profile 构成真实设备输入边界；离线后端仅用于隔离检查。
门禁验证完整帧身份、场景、应用、时效、许可和位置，并串行映射/发送输入。
记录 attempted/accepted/rejected/backend_called；停止时只允许真实释放此前按下的键/触点。
后续由设备 profile 确定唯一真实目标，不在门禁里自动扫描或选择设备。
ADB、MuMu IPC 的能力与故障必须明确记录，不能全局重启 ADB 或误操作另一实例。
设备层处理连接与触摸，不判断战斗是否完成；游戏恢复顺序由 WVD 恢复层请求。
MuMu 特有的进程操作只能下沉到 Windows 平台层。

每次输入前的前台夹持检查采用一个 ADB 客户端事务：window → input viewport → window，三段标记和各自返回码全部校验。成功事务本身证明 transport 可达，不再另起 get-state；不是设备端原子快照。总响应上限 8 MiB、单段 2 MiB，重复/缺失标记、非零返回、旋转/分辨率/前台/代次变化或取消均拒绝输入，不退回多客户端旧路径。截帧元数据的完成时间与像素采集开始/结束时间分开，不刷新旧图年龄。
