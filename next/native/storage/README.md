# 存储层（M2 / M4）

不建数据库，不读取或写入用户 config/mod。M2 的 `RunStore` 新建运行快照并原子提交结果；
`EventJournal` 记录有界事件并保留终态提交槽，运行状态决策权仍属于 runtime。
数据属性、读写所有者、隔离目录和失败文件边界见 `../../docs/data-authority.md`。
配置 revision、旧配置导入和长期保留策略不在当前实现中，属于后续对应阶段。
导入须保持未知键、任务覆盖顺序、SKIP 字段的原存储语义，不能让 GUI 成为第二写入权威。
新增持久化类型时须同步更新数据事实文档，验收继续使用独立测试目录。
