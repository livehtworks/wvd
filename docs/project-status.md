# 项目当前事实

## 当前产品

- 旧版 Python/Tkinter 程序仍保留，未覆盖 `src/`、旧 `config.json`、`mod`、日志或 `dist/wvd`。
- 新版 Windows 可操作程序位于 `next/`，技术底座为 C++20、MaaFramework 5.13.0、OpenCV 4.12.0、Boost.Beast 与 Vue 3。
- 新版唯一服务入口为 `next/native/app/main.cpp`，装配层为 `next/native/app/application.*`；设备、运行、配置和流程数据均由后端持有，Vue 不自行模拟状态。
- 可双击交付目录为 `next/dist/wvd-next`，入口为 `启动WVD新版.bat`。新版用户数据保存在 `%LOCALAPPDATA%\WvdNext`。

## 已接通能力

> **阻断状态（2026-09-22）：** WVD Next 的真实任务链为 `NOT_DELIVERABLE`，且已停止实机运行。新旧链静态审计与最后一次真实运行共同证明：共用动作执行器错误地把输入提交、页面转场和业务完成合并为一次同步事务，并将 `2000ms` 输入帧龄复用于点击后和业务确认。真实记录中点击已发送、目标识别成功，仍因识别耗时 `4253ms` 被判为 `SCENE_UNCONFIRMED`。该缺陷影响全部点击/滑动流程，不是启动页局部问题；当前启动页补丁也不能解决根因。详见 `next/docs/runtime-chain-incident-audit-20260922.md`。

- 工作台可编辑并保存模拟器、目标、探索、战斗、战斗方案、任务点、日常和高级设置；战斗方案通过左侧可搜索列表切换，右侧只编辑当前方案；旧配置只读导入新版副本。
- 明确选定 MuMu 路径、ADB 地址和实例编号后，可从界面连接、断开、截图并显示异步失败原因；截图与任务执行共用设备所有权。
- 可直接运行现有任务，启动定义读取所选任务的有效配置；生命周期恢复继续承接游戏启动、重连和已启用的 Clash/VPN。
- 流程编辑器支持新建、复制、保存、删除、任务转编辑副本、节点参数、连接语义、撤销/重做、选中节点调试、已保存版本运行和停止。
- 作者流程已接入识别、受控点击/滑动/返回键、可中断等待、有限重复、失败出口、战斗/开箱/业务确认和现有任务阶段。
- 试识别支持当前帧和 900x1600 本地 PNG；模板、OCR 与 WVD 既有识别模式返回 `Hit / NoHit / Error`，不触发设备输入。
- 运行结果显示真实 Run 状态、当前编辑节点、耗时、输入统计、失败原因和有界诊断截图。

## 本轮实操事实

- 从成品工作台连接用户选定的 MuMu 实例，任务为 `[悬赏]蝎女`，策略为 `法术+地裂`。
- 初始“VPN 关 / 游戏关”首次运行安全失败于 `VPN_UI_DUMP_FAILED`；没有游戏输入、游戏/模拟器重启或资源消费。
- 修复后定向复验真实完成 `EnsureVpn` 与 `StartApplication`，`tun0`、游戏进程及游戏前台均被确认；随后因启动页只扫描一轮，在繁中免责声明上以 `recovery.boot_ready.budget_exhausted` 结束。诊断截图与模板离线匹配约为 `1.0`，证明模板本身有效。
- 为未知启动帧加入 `500ms` 可取消轮询、保留原 `120s` 总预算后，下一次定向复验在 VPN 的画面方向门禁处安全失败；实际帧为 `900x1600`，没有输入。门禁已改为只接受实测的 `900x1600 / 1600x900` Clash 主界面，但按工作包首失败停止规则未再次实机运行。
- 最终服务已停止；MuMu 实例仍运行，VPN 关闭，游戏关闭，模拟器重启次数为 `0`。
- 此后静态审计确认：`GuardedAction` 默认要求动作后短时命中后置条件，后置结果又被 `max_frame_age=2000ms` 拒绝；默认错误出口会把普通转场延迟升级为恢复。蝎女任务还存在从王城无法进入因果轮的入口倒置，恢复会话存在 backend 已断开的问题，底层同步等待也不能保证停止及时返回。

## 保留边界

- 本轮不以全任务矩阵作为交付前置；具体游戏任务效果仍由用户从完成的界面实操后按实际问题修复。
- 在动作、观察、业务确认重新分层并完成静态核对前，禁止继续实机运行；不得通过扩大超时、放宽阈值或重复测试掩盖执行模型错误。
- `RESOURCE_UNRESOLVED`、少数复杂识别的成本和任意第三方原生阻塞的取消边界仍保留，不据此声称长期挂机稳定性已经证明。
- 新版是独立可操作版本，尚未替换旧版默认生产入口，也没有新增安装器、自动更新或跨平台实现。
- 最终候选位于 `next/dist/wvd-next`，但在真实四组合和安全任务步骤完成前不得标记为可用版。
