# 项目当前事实

## 当前产品

- 旧版 Python/Tkinter 程序、`config.json`、`mod`、日志和 `dist/wvd` 未修改；原有 `next/dist/wvd-next` 也未替换。
- Windows Next 的活动服务由 `next/native/app/main.cpp` 启动，`Application` 装配唯一原生 `FlowExecutor`、MuMu/ADB/scrcpy 设备会话和 OpenCV/ORT 识别。Vue 通过同源 API 编辑配置、战斗方案和作者流程。
- 独立候选在 `next/dist/wvd-next-native`，入口为 `启动WVD原生版.bat`；数据目录为 `%LOCALAPPDATA%/WvdNext`。候选不是生产切换。
- Maa SDK 集成源码和旧阶段工具/测试已移至 `next/archive/`；当前 CMake、构建和有限验收不调用 Maa。
- 当前修复工作树基于 `8f61540`，本轮 R01-R10 的具体实现、构建和未验边界见 [修复收口](repair-8f61540-closure.md)。候选的实际 commit、未提交 diff、EXE、前端和资源身份以 `next/dist/wvd-next-native/DELIVERY_STATUS.json` 为准；打包不等于实机通过。
- OpenCV 34 MB 分配异常的证据与当前代码峰值风险已单列在 [内存复核报告](opencv-memory-review-20260925.md)；目前没有足够证据认定泄漏或宣布资源稳定。

## 已有证据

- 锁定依赖通过哈希校验，独立目录 Windows Release 与 Vue 构建并打包。直接 OpenCV 模板、真实 ORT 英文 OCR、原生执行器、双事件退出、scrcpy/ADB 报文、公共 slot 六轮/两处调用及协调器的定向离线检查通过。
- 正式 `Application` API 在隔离数据目录完成作者流程保存、应用重开、编译、执行、根业务终点及结果落盘；同一应用入口能带 `ACTIVE_BEG_MONEY` 装配蝎女原生任务并进入 `Task_` 步骤。协调器的延期恢复可响应停止。离线后端禁止游戏输入，不表示任务实机通过。
- 候选在桌面及 390px 手机浏览器中完成工作台配置保存重开和页面切换；候选进程实际加载自身目录 OpenCV/ORT，PE 导入无 Maa。先前旧引擎的实操不能转记为新链结果。新链在隔离候选上已连接真实 MuMu，并通过同一 Application API 实跑一次王城→公会→委托→悬赏列表（2 次输入，终态 Completed）；从悬赏列表再次运行打开悬赏页，以 0 次输入完成。此次不是工作台 UI 点击验收，也不代表完整任务通过，见 [实机记录](../next/docs/native-real-device-validation-53718f1-20260924.md)。
- 最新候选还通过正式 API 的公共流程引用删除保护、编辑器撤销/重做/保存重开和 CaptureHost 人为挂死回收。对应证据与未完成断言统一记录在 [Maa 移除工作包执行记录](../next/docs/native-removal-acceptance.md)；产品离线验收仍为 `PARTIAL`。
- 已保存的繁中 PNG 进入源语义目录和资源包；另有公会、宝箱和战斗现场局部模板。内置任务通过显式游戏素材语言在发布前映射已确认的选项与战斗按钮；作者流程直接按语义 ID 选图。打包与素材匹配不等于完整任务通过。
- 本轮游戏素材语言为空时保留原生明确图片；非法语言在连接设备前拒绝。公共公会开页定义设显式本地更新状态，旧用户文档不静默覆盖。原生赏金 Reveal 复用同一公共定义；缺可靠繁中提交证据的 Report 仍安全阻断。
- 宝箱现场已走过繁中“打開”到选人、拆锁和多页奖励；正式探针确认新奖励箭头与繁中战斗标识的正/负样本。奖励页退出后先回迷宫再遇怪，不能认作宝箱怪。证据和未测分支见 [宝箱实机记录](../next/docs/chest-live-20260924.md)。
- 繁中战斗实帧确认白色“自動”为关闭、橙色“自動”为开启；“逃跑”菜单锚点、自动开关与自动战斗子流程已接入。产品识别探针对开关前后两帧和战后迷宫帧的正/负结果符合预期；尚未由原生流程实际执行完整技能策略。
- 大地图当前名称可见的缩放档采集 20 个繁中地名；19 个地点已手动进入并记录页面类型，瓦里安大草原未进入。城市右下地图入口和可选普通剧情继续箭头已接入导航候选；只读地点资源先确认地图场景，避开复用建筑图标和随机标记。记录见 [大地图采集](../next/docs/world-map-capture-20260924.md)。

## 剩余边界

- 原生任务工厂已改用项目中立的编译期图字段，发布后运行时只消费强类型 `FlowProgram`；工厂直接构造强类型步骤仍待完成。
- R01-R10 修复候选只完成构建和针对性静态/原生检查，尚未获得用户选定的本轮实机操作范围；工作台按钮、公会菜单、普通业务失败/事件以及宝箱内存异常的本轮现场结果均不可记为通过。OpenCV 34 MB 分配失败保留未归因。
- 城市公共配方、繁中公会页及开箱/选人/奖励动态探针由语义源生成于构建期；其余内部启动/地点探针的发布期依赖冻结尚未全部统一。作者语义调用、旧原生兼容和诊断使用同一解析规则的工作仍有边界，详见收口文档。
- 原有任务的完整副作用、事件嵌套、交接/续段、停止与恢复尚未在正式新链逐项证明。尤其公会领取、入本、战斗、悬赏提交和完整蝎女任务不能宣称可用。
- 当前公会截图仅覆盖入口、页签和页标题；完成报告、第一项提交等动作不能拿截图里的“奖励确认”代替，须继续按真实语义核定。素材匹配与候选打包不等于任务能真实运行。
- 宝箱流程已补繁中入口、选人、连续奖励页及战斗交接识别。最终隔离候选实跑到下一宝箱，但单独开箱流程在过渡帧以 `BlockedExit` 结束；完整任务父链、无奖励、陷阱、直接宝箱怪和慢网络切帧未实测。一次 OpenCV 内存分配失败未归因。当前遭遇战曾靠人工点一次游戏内“自动”清除；繁中战斗按钮虽已接入并完成识别探针，原生自动点击和技能策略输入链尚未实机验收。
- 真实 MuMu 的完整任务流程、工作台 UI 触发、停止/恢复等仍未验收。普通委托页→悬赏页的页签横移分支已单独实跑，但不等于完整任务验收。不得自行领取、领奖、跳轮、购买或讨伐。
- 大地图名称素材只作为观察证据；旧 `City_*` 建筑点击路径尚未用新名称模板替换，地名识别命中不代表能安全点击入城/入本。普通剧情分支仅用已存现场帧验证，未在可重现剧情中实跑；城市身份、非通用二级页及其它地图缩放仍待自动流程验证。
