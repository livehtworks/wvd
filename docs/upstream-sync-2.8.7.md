## 合并时修正的衔接问题

- 钓鱼启动恢复识别包括下杆、拉杆和结果页；网络/标题处理接入本地公共阻塞界面处理。
- 鱼饵补给的等待被停止打断后，先检查 None 再访问坐标；70 次取鱼饵和转向循环检查停止事件。
- 拉杆超时后的旧画面作废，下一轮重新截图；转向每次检查是否已经出现钓鱼界面，不盲目打完全部滑动。
- 未知画面仅在地下城视角执行转向；其他界面保存限频诊断，持续 90 秒无有效状态时记录现场再恢复。
- 楼层检查返回统一的 DONE/FAIL/WRONGFLOOR，所有调用者同步切换；AutoMove 冻结检测仍使用本地函数。
- 打包在临时目录完成后才更新程序资源，仅清理生成的 _internal；保留 config.json、logs、mod 和其他用户文件。同名但其他路径的进程不影响本次构建。

## 保留本地实现的项目

| 上游改动 | 当前决定和理由 |
| --- | --- |
| logging 切换 loguru | 不引入第二套日志框架。上游 GUI sink 仍直接从后台线程操作 Tk；沿用本地日志队列、摘要过滤与界面批量刷新 |
| 战斗箭头方向场替代 NEXT | 保留本地 NEXT 多尺度亮色遮罩、三角标记和低阈值兜底。上游响应按当帧最大值归一化，并非绝对置信度；没有当前实机正负样本前不替换已验证的目标选择链 |
| 按策略分别设置入本/战斗重置 | 本轮未接入，继续使用原全局 RELOAD_STRATEGY_WHEN。直接切换会令旧配置中的重置要求失效，需另做明确配置升级方案 |
| SKIP_* 改名为 DO_* | 仅更新 UI 文案，不更名或翻转持久化字段，无兼容别名和双份配置 |
| 匿名人物模板重命名 | 不重命名，保留原策略引用；仅增加新人物 |
| 截图时吞掉异常继续 | 不采用；保留截图错误和 RestartSignal 的真实传播，由任务执行入口负责恢复 |

MuMu IPC/ADB 后端、Clash/VPN、Pause/AutoMove 冻结识别、NEXT 点击停止边界、头像识别、宝箱转战斗防连点、GUI 线程结束通知、世界地图入城确认、FFXI 住宿均保留。
