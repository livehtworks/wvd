## 当前改动

- 战斗以结束画面为终点，删除最多 16 次角色处理的接口及分支。每次角色处理仍重新识别，不复用上一角色的点击许可。
- 移除迷宫正常分派、战斗、宝箱和选点的 128 次经过限制，以及奖励页的 20 次经过限制。作者显式业务重复次数与用户停止语义保留。
- 启动/共用恢复的网络、对话、死亡提示等正常观察/子调用及返城分派不再累计经过次数。输入仍只计连续未确认尝试；报告数量等业务约束不借本次修复删除。
- Poll 增加可选业务进展证据。移动看小地图，自动战斗看行动条，只有新帧区域变化才刷新无进展期限；单纯仍处于战斗或迷宫不能续期。每个会话最多保留两个小灰度样本，不观察火焰等全屏背景动画。FlowProgram schema 为 7。
- 打开小地图、Auto-Move、选技能等级、技能确认、倍速、开箱、关闭技能详情和开启 Auto 接入同页间隔重试。每次重新检查场景、目标和结果，并经过原输入门禁；新帧已确认结果后不重发。
- 已声明可重复的动作，多次尝试后仍能确认原页，可结束本次未生效尝试并进入业务错误分支。此行为不记为动作成功，也不适用于送达未知或不可重复的付款操作。
- 技能确认未生效可进入原有自动战斗兜底；选级未生效可交接调用者，而不是在等待层吞掉后续分支。
- Auto-Move 不再单击后三秒就判冻结。只有同页连续重试仍无进展才进入恢复。完整地图搜索未找到同一目标时先重搜，搜索失败不等于正常经过一次地图。
- 已确认导航无响应、Auto-Move 冻结或自动战斗无进展的失败原因接入现有仅重启游戏的恢复策略；未确认付款、送达未知和普通配置错误不因此放开重启。
- Auto 开关必须确认启用状态，不能拿“仍是战斗画面”冒充启用成功；未知开关状态的两次观察之间加入等待，避免同一帧充当多次采样。
- 手动战斗同样建立行动条进展基线，不能靠不断成功调用空动作来逃过无进展观察。跨越超过15秒的未观察间隔重新建立计时，不能把网络处理/子流程期间未经采样的时间当成静止证据。
- 繁中离店改为直接匹配“離開”中心；启动与住宿后均可从明确识别的人物详情页关闭返回，不重复购买房间。输入日志补充实际坐标与目标中心。
- 区域静止条件修正同帧重入：选路命中后输入前复核保持同一结论；按最后采样时间计算，不因重复读取旧帧累积静止时间。
