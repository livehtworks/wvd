## 真实调用链与代码入口

1. 工作台/守护脚本调用正式 `/api/v1/runs/start`，`Application` 冻结配置与资源，`NativeRunCoordinator` 创建正式 `NativeExecutionSession`。
2. `FlowExecutor::select_next()` 对候选共用一帧；`PipelineCompiler::compile_interruption()` 为节点附加阻塞页反证。先前不同复合识别请求重建局部 memo，造成相同叶子重复计算。
3. `recognition::Service` 按帧身份管理缓存。`games::vision::evaluate()` 以资源版本、语言、对话任务、作用域及模板参数区分叶子；帧身份变化时清空。业务状态、运动历史不进入新增叶子缓存；异常不作为正常负样本保存。
4. `take_turn()` 识别角色及配置技能，打开详情，识别/点击等级，再以新帧选中态确认，之后才确认技能或选择目标。
5. 战斗结束进入恢复，再通过快捷返哈肯、归还城市、公会报告及按间隔住宿结束完整业务循环。

重点源码：

- `next/native/games/wvd/tasks/bounty_cycle.cpp`：`scorpion_plan()` 的普通路线。
- `next/native/games/wvd/tasks/{task_plan,dungeon_route}.cpp`：哈肯目标类型及独立终点确认。
- `next/native/games/wvd/navigation/harken_exit.cpp`：剧情优先、城市完成条件、有限继续。
- `next/native/games/wvd/recovery/boot.cpp`：`retry_network_prompt()`、`with_boot_recovery()` 的事件注册与父流程恢复。
- `next/native/games/wvd/vision/{network_probes,boot_probes}.hpp`：网络正文/按钮及语言检查顺序。
- `next/native/recognition/{custom.hpp,service.cpp}` 与 `next/native/games/wvd/vision/native_recognizers.cpp`：帧内缓存、并行 memo、等级选中态。
- `next/native/games/wvd/combat/turn.cpp`：等级选择、确认、降为一级与默认等级的出口。

## 有界行为与安全语义

- 新叶子缓存与原复合缓存合计最多 128 项、1 MiB；不新增跨帧像素缓存。统计包含两类结果。换帧清空由正式 Service 负责，不由调用方猜测。
- 模板判断不借短路吞掉已执行识别错误；并行 worker 不写共享 map，结束后合并纯模板证据。
- 网络处理总预算 180 秒，单次按钮消失等待最多 120 秒，最多 20 次重试；父等待由现有事件机制挂起，返回后重观测原后置条件，不重放提交、付款、跳轮。
- 网络处理器不注册到自身和共享 `RequireRecovery` 出口，避免 `FLOW_CALL_CYCLE`。未知维护/其它错误页不靠通用确认强行继续。
- 普通剧情只点已识别继续箭头，间隔 700ms，最多 50 次，仍受 180 秒总预算。带选项的未知剧情不自动代选。
- 等级先定位按钮，再检查中心周围 110×60 区域的金色比例，HSV 范围 H=10..45、S/V>=100，比例至少 0.05。此阈值只获当前样本支持，不能称为跨场景可靠性已证明。

## 未解决问题与建议审核重点

1. **整次技能仍约 21.6 秒**。每个新帧上的全局反证、多个观察节点、输入前门禁、后置等待仍有成本。应审查实际必要调用，不能简单删掉安全确认或降低阈值换速度。
2. **取帧含元数据的总耗时没有测量拆分**。`DeviceSession::capture_impl()` 走 IPC RGBA→BGR→翻转；仅 ADB 后备取图使用 PNG 解码，预览另行编码。`capture_finished_at` 在前台/方向 ADB 查询前记录，无法代表含这些查询的完整调用耗时；下一步只在真实流程做取帧、元数据、识别、输入及后置等待的有限分段计时。
3. **内存仍未归因**。本轮识别日志采样私有提交峰值 971,223,040 字节（926.23 MiB）；不是缓存上限，也不是已证明泄漏或内存稳定。审核有界结果缓存是否正确，不把它当作已消除 OpenCV 工作区与进程峰值。
4. **网络/剧情异常实际恢复未验**。正常循环成功不能代替随机覆盖层触发、嵌套、超限与父输入恢复证据。重点审查事件自身注册、暂停预算、返回层级及是否存在重放动作的路径。
5. **选级覆盖有限**。当前真实 Lv5 和旧 Lv3 样本支持此修复，但全部 Lv1-Lv7 的选中态、描述变化引起布局移动、不可用等级及资源不足退一级未逐项实测；Lv8/Lv9 仍使用已有素材路径，没有新增现场模板。
6. **语言优先不是语言全覆盖**。当前循环显式繁中，已有公共探针繁中优先；OCR 仍是锁定英文模型。请避免据“繁中优先”推导出繁中 OCR、全部 UI 或任意语言自动切换已实现。
7. **诊断计时语义**。历史 JPEG 至多每 15 秒保存一张，不是取帧周期；步骤间隔也不是单次识别时长。请核对报告是否混用这三种时间尺度。

建议先审核真实调用链、缓存边界和选级许可，再给出针对剩余 21.6 秒的最小改动方案。不要以继续跑大矩阵、离线通过数量或长时内存测试替代当前用户可操作功能。
