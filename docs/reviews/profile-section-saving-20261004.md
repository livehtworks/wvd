# 工作台分区保存

## 范围与边界

- 移除工作台右上角全局保存按钮。任务设置、常用参数、战斗方案、设备与高级分别设置本区保存按钮、未保存状态及结果提示；方案保存位于编辑区底部并随滚动保持可见。
- 沿用现有 profile 文件及 CAS 写入入口，不建立浏览器配置副本或第二套持久化权威。原生 catalog 给出唯一字段分区；局部请求只提交本区字段，服务端拒绝越界字段、越界日志和越界名称变更。
- 任务区保存目标和任务覆盖选择。其它区保存必须先确定任务上下文；切换目标从该目标的已保存有效配置加载，不能把上一任务的覆盖复制过去。循环次数是运行请求参数，识别语言沿用现有运行偏好，两者不混入旧游戏配置字段。
- 常用参数包含恢复、开箱、住宿及方案引用；战斗区包含方案及重置时机；设备与高级包含设备、VPN、日常/高级设置及日志分级。
- 方案更名在同一个事务中重绑定已保存引用，这是维护引用完整性的必要变化，不提交其它区域的草稿。未保存的新方案不可直接成为已保存常用参数的引用。
- 保存响应推进唯一 revision，只结清本区。其它区域的配置草稿、日志草稿及尚未确认的名称编辑保持；失败不丢弃草稿。浏览器刷新/关闭及跨页面导航对未保存编辑进行确认。
