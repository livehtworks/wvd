# 战斗编辑与调试

## 本轮范围

- 方案列表、角色动作行均可用独立手柄拖动；显示序号、交替底色。排序保留选择与原数组权威，上下移动仍作为键盘替代操作。
- 选中方案具有开始/停止调试入口，自动保存战斗区草稿后以准确revision提交。原生端取新鲜帧确认游戏前台和战斗，复用原战斗编译、输入门禁、协调器、停止及诊断；只处理当前战斗，不拉起、重启游戏或运行副本循环。
- 可从当前游戏截图或上传图框选行动条头像，添加怪物名称和方案；支持多只怪物各自绑定方案。分类搜索整个行动条，优先第一个匹配规则，未命中按原普通方案；红骷髅保留为未命中具体头像后的原特殊方案条件。第一次接管列表显式保留旧单头像规则。
- 头像PNG嵌入原profile，发布时派生内容寻址图像包，再经原发布器冻结；没有第二套可写素材注册表。PNG头部限制先于解码，防止压缩小文件触发巨大分配。规则属于常用参数区，战斗方案仍独立保存。

## 验收边界

本轮只做对应的拖动、保存重载、缩略图、调试提交和原生装配/发布定向核对，不重跑旧全任务矩阵。隔离profile与端口不写正式配置。受控调试提交只证明UI请求，原生城市场景拒绝只证明非战斗不会发输入；均不冒充真实施放成功。

用户明确选择由本人点击调试，代理不得施放技能、开启任务或循环。
