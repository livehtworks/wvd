## 共同缺陷

执行器有唯一的retry_pending_input实现：每次先查结果，再重认原页、按钮和重试许可；同页补点不改变原结果期限，也不结算业务。遗漏在各生产工厂和公共定义未声明这项许可，造成单击送达后一直等待。

另一类节点以后置包含原页的方式立即返回局部分派，再由当前视觉决定下一动作。这些不是同一种“只点一次然后Await死等”，不能仅按有没有retry字段批量改。切页、导航、战斗施放、领奖、道具转移、计时复活和Auto双击也不能共用未经分类的重复许可。
